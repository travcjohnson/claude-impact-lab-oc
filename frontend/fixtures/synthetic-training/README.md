# Invented upload fixtures

These six-page documents were authored for Careward testing using the section
structure of the supplied public blank referral form/checklist. No actual referral
packet content or identifiers were copied. Every page is labeled synthetic.

The text PDF includes an intentional summary/therapy conflict, undocumented
medication self-administration, withheld dates and an authorization request without
approval. The scanned PDF contains identical page content as grayscale images;
text extraction needs OCR. Neither establishes clinical eligibility.

Only these exact PDFs are included in the deployment allowlist. Repository hygiene
tests pin their hashes. Runtime uploads and event packets must never be placed here.
